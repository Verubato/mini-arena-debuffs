# MiniArenaDebuffs

Simple addon that shows debuffs on arena frames.

Features:

- Option to show only your debuffs.
- Debuffs sorted by time remaining.
- Change the position of the debuff frames.
- Change the size of the debuff icons.
- Anchor to different arena frame addons, e.g. sArena, GladiusEx, and anything else.
- Test mode with fake arena frames so you can configure settings without having to enter arena.
- Works in Midnight.

This is useful for tracking dots, e.g.:

- Ele flame shocks.
- Feral dots (e.g. rake/rip)
- Lock dots (e.g. UA/agony/corruption/wither).
- Moonkin dots (moonfire/sunfire).
- Spriest dots.
- Unholy DK dots.

*Note: it's not possible to filter what specific debuffs can/can't be shown in Midnight (e.g. only show flame shock) like it was in previous expansions.*

This is a brand new addon and features will be added over time.

Feedback and feature requests are more than welcome!
